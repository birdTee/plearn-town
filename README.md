# Plearn Town

เกมโลกโรงเรียนออนไลน์สำหรับนักเรียน ป.5 — เรียนเพลิน เล่นกับเพื่อน

- `index.html`, `config.js`, `sprites/`, `*.webp` — ตัวเกม (ขึ้นเว็บด้วย Vercel)
- `server/` — เซิร์ฟเวอร์ออนไลน์ (ขึ้นด้วย Render, Root Directory = `server`)
- `config.js` — ใส่ที่อยู่เซิร์ฟเวอร์ `wss://...onrender.com`
